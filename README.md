поменяй `INFO` и напиши хендлеры на `router`. Перезапусти бота.

`bot.py` — только `/start` + `📂 Категории` + whitelist.

## Зеркала — каждый сидит в своём

Общий бот не дрочим. Каждый поднимает личное зеркало:
1. Форк репо, `cp .env.example .env`
2. `BOT_TOKEN` у @BotFather, `ALLOWED_USERS`=свой id, `INSTANCE_NAME`, `OWNER`, `FORK_OF`=откуда взял
3. `pip install -r requirements.txt`, `python bot.py`
4. В `ℹ️ Инфо` видно: версия из `VERSION`, исходник `SOURCE_URL`, чей форк.

Правила: `SOURCE_URL` не менять, `FORK_OF` указывать честно.

## Как запустить

1. **Получи API-ключи** на https://my.telegram.org → "My Apps" → создать приложение.
   Скопируй `API_ID` и `API_HASH`.

2. **Создай бота** у @BotFather, получи `BOT_TOKEN`.

3. **Установи зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создай `.env`** рядом с `bot.py` (скопируй `.env.example` и заполни):
   ```bash
   cp .env.example .env
   ```

5. **Запусти:**
   ```bash
   python bot.py
   ```

## Как пользоваться (в Telegram)

1. `/start` → нажми **➕ Создать сессию** и введи имя аккаунта (напр. `acc1`).
2. Поделись номером (кнопка «📱 Поделиться номером») или введи `+375...`.
3. Введи код из Telegram. Если включена 2FA — введи пароль.
4. Повтори для остальных аккаунтов (каждый — своя сессия в `sessions/`).
5. **👥 Мои аккаунты** → отметь ✅ те, что будут слать (можно несколько).
6. **📥 Загрузить список чатов** и пришли `.txt` файл.
   Формат — одна ссылка/юзернейм на строку:
   ```
   https://t.me/channel_one
   @username
   https://t.me/+inviteHash
   -1001234567890
   ```
7. **✉️ Текст рассылки** → выбери шаблон (подставишь `{link}`) или введи свой текст.
8. **🚀 Старт рассылки** → подтверди. Список чатов **распределяется между
   выбранными аккаунтами**, и они шлют **параллельно** (общий прогресс-бар).

## Мультиаккаунт и параллельность

- Каждый аккаунт = отдельный файл сессии `sessions/<имя>.session`.
- В «👥 Мои аккаунты» выбираешь, какие пустят в рассылку (мультивыбор).
- При старте чаты делятся между аккаунтами (round-robin), и отправка идёт
  через `asyncio.gather` — то есть все выбранные аккаунты работают одновременно.
  Нагрузка на каждый аккаунт меньше, прогресс-бар — общий.

## Доступ (whitelist)

В `.env` укажи `ALLOWED_USERS` — список твоих Telegram user_id через запятую
(узнать свой — бот @userinfobot). Левые юзеры получат «⛔ Нет доступа».
Если оставить пустым — бот доступен всем (небезопасно, только для первого теста).

## Тест-режим (без реальной отправки)

Чтобы проверить весь флоу (парсинг списка, прогресс-бар, подстановку `{link}`, статистику)
**без риска что-либо отправить**, есть два пути:

- кнопка **🧪 Тест-прогон** в меню — сразу имитирует рассылку по загруженному списку;
- либо в `.env` поставь `TEST_MODE=1` — тогда и «🚀 Старт рассылки» тоже пойдёт в холостую.

В тест-режиме сообщения **не уходят** в Telegram, счётчики просто накручиваются.

## Важное

- Только свои чаты, где аккаунт админ и имеет право писать. Чужие чаты будут `skipped` — так и задумано.
- Telegram ограничивает массовую отправку из аккаунта (ошибки `FloodWait`).
  Бот их ловит и ждёт указанное время. Увеличь `DELAY` в `.env`, если часто вылетает.
- Сессия хранится в `sessions/<имя>.session` — это по сути доступ к твоему аккаунту,
  никому её не передавай.
- Рассылка по чужим чатам без согласия — нарушение ToS Telegram и бан.
